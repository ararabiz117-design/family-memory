# 架空データ規約

開発、テスト、スクリーンショット、動画、障害報告には、実在人物の情報を使いません。

## 使用できるデータ

- 姓は `青葉`、`星野`、`水野` など、テスト専用であると説明できる組み合わせを使う。
- メールは `example.com`、電話は `000-0000-0000`、住所は `架空県みどり市` のように実在性を否定できる値を使う。
- 顔写真は使わず、色付きの頭文字、幾何学図形、明示的に生成された架空イラストを使う。
- 墓所、寺院、戒名、金額には「テスト用」または「架空」を含める。
- 招待tokenとOTPは固定fixtureであってもログへ出さない。

## 禁止するデータ

- 家族、親戚、知人、著名人を含む実在人物の氏名、顔、住所、連絡先、生年月日、命日。
- 実在する戒名、宗派と人物の組み合わせ、墓所の区画、法要費用、参列者。
- マイナンバー、口座、カード、パスワード、医療情報。
- 実運用のSupabase URL、鍵、署名情報、招待URL、OTP。

## テスト用標準家族

- 家族スペース: `青葉家（架空データ）`
- 青葉みどり: owner、存命
- 青葉そら: editor、存命
- 青葉つむぎ: viewer、存命
- 青葉まもる: 故人、命日は `2020-05`（年月精度）
- 星野ゆかり: 関係者、表示関係は `まもるの従姉（架空）`
- 場所: `みどり霊園・テスト区画 A-00`
- 行事: `まもる 一周忌（テスト記録）`

## 混入時

配布を止め、履歴・成果物・ログを対象に漏えい範囲を確認し、削除と必要な鍵交換を行います。実在性に迷う値は使用しません。
