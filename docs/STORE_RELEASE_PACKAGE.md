# ストア提出準備パッケージ

更新日: 2026-09-12

この文書は、家族限定βの実機試験後にGoogle Play ConsoleとApp Store Connectへ転記するための草案です。運営者名、問い合わせ先、プライバシーポリシーURLを確定するまでは提出しません。

## アプリ基本情報

- アプリ名: 家族の記憶
- Android applicationId: `jp.familymemory.app`
- iOS bundle ID候補: `jp.familymemory.app`
- カテゴリ候補: ライフスタイル
- 対応: Android優先、iPhone、認証必須Web
- 初版価格: 無料
- 広告、課金、行動解析SDK、外部AI送信: なし

## 短い説明

家系図、故人、法事、墓所、贈答、親族とのつながりを、招待した家族だけで共有する記録アプリです。

## 詳細説明

「家族の記憶」は、葬儀や法事で「前回はどうしたか」「この方は誰か」を家族で確認するための非公開アプリです。家系図、顔写真付き関係者帳、故人の命日・戒名・宗派、墓所や寺院、法事の会場・参加者・費用、お中元やお歳暮の履歴を一つの家族スペースへ記録できます。

法要日は候補として表示し、宗派・地域・寺院・家庭による違いを家族が確認してから確定します。承認済みの家族だけが閲覧でき、owner、editor、viewerの権限を設けています。

## Google Play Data safety / App Store App Privacy草案

アプリの実装と利用者入力により、次の情報を収集・保存する可能性があります。

- 連絡先情報: ログイン用メールアドレス、任意の電話・メール・LINE名
- ユーザーコンテンツ: 氏名、家族関係、故人情報、法事・贈答記録、自由記述
- 写真と文書: 利用者が明示的に選択した人物・場所・行事の添付
- 概算ではない場所情報: 利用者が入力した住所・墓所区画・行き方。端末の常時位置情報は取得しない
- アプリ操作情報: 変更者、操作対象、操作種別、日時。行動広告・第三者解析には利用しない
- 認証情報: OTPそのものは保存せず、認証サービスがセッションを管理する

利用目的はアプリ機能、家族内共有、認証、セキュリティ、不具合対応に限定する。広告目的の追跡、データ販売、顔認識、AI学習への送信は行わない。

## 権限の説明

- インターネット: Supabase認証、家族共有、非公開添付の送受信に使用
- 通知: 利用者が確定した予定について、設定した日数前に端末内通知を表示
- 写真選択: 利用者が明示的に選んだ写真・文書を添付するために使用。写真ライブラリ全体を収集しない
- 位置情報: 初版では要求しない
- カメラ: 初版で直接撮影を実装しない場合は要求しない

## 審査用デモ手順

1. 審査専用の架空Googleアカウントまたはメールアカウントを作成する。
2. 架空データだけの審査用家族スペースを用意する。
3. owner用Googleログイン手順を審査メモへ記載する。メール認証を使う場合だけメールリンク／確認コードの取得方法も記載する。
4. 「誰だっけ？」検索、家系図、法事履歴、費用、墓所、通知設定、削除手順を審査メモへ記載する。
5. 実在人物・実在住所・実在の戒名・実在家族メールを審査アカウントへ入れない。

## 提出直前に確定する項目

- 運営者名
- 受信確認済みの問い合わせ先
- HTTPSのプライバシーポリシーURL
- サポートURL
- iOSのApple Developer Teamとbundle ID
- Android専用release keystoreと安全な保管場所
- 本番Supabaseプロジェクト、正式Web origin、custom SMTP送信元
- スクリーンショット、フィーチャーグラフィック、年齢区分
- 実装と一致するData safety / App Privacy回答
