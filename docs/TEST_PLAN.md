# テスト計画 — 家族限定β

## 判定の原則

自動テストの成功だけでは配布可能としません。Flutterのunit/widget、Supabase RLS負テスト、Android実機、iPhone実機、認証必須Web、削除・復元を組み合わせます。すべて架空データで実施します。

## 自動テスト

### ドメイン

- 不完全日付: 年のみ、年月、年月日、不明を相互変換しても精度を失わない。
- 金額: 0〜100,000,000円の整数だけを受理し、合計が一致する。
- 法要候補: 候補日と確定予定日を別に保持し、候補だけでは通知しない。
- 前回複製: 種別、対象、場所、説明、参加者候補、費目名だけを引き継ぐ。日付、状態、出欠、人数、金額、添付、当日メモを空にする。
- 競合: `version` 不一致を成功扱いせず、再編集導線を返す。
- 権限: viewerは変更不可、owner専用操作をeditor/viewerから拒否する。

### Widget

- 下部タブが `ホーム／家系図／記録／人物` の順で存在する。
- ホームから `誰だっけ？` と `前回どうした？` を直接開始できる。
- 「誰だっけ？」は2〜3タップで関係と会った場面に到達できる。
- 「前回どうした？」は3タップ以内で場所、費用合計、参加人数を確認できる。
- viewerに追加・編集・削除・出力操作を表示しない。
- 保存失敗、部分成功、競合を「保存しました」と表示しない。
- 320px幅、文字200%で例外・overflowがなく主要操作へ到達できる。
- 通知本文は固定文言 `家族の予定を確認してください` だけを使う。

### RLS・API

- 未ログイン、別家族、退会済み、招待accept前、owner承認前は業務データ0件。
- family_idを差し替えた全CRUDを拒否する。
- viewerのinsert/update/delete、editorの招待・権限・全削除・exportを拒否する。
- 招待の期限切れ、再利用、取消、再送前tokenを拒否する。
- 唯一ownerの退会・降格を拒否する。
- private Storageで別家族path、推測path、期限切れsigned URLを拒否する。
- 版番号不一致の更新を無条件上書きしない。

## 手動受入

owner、editor、viewerの3アカウントで同じ架空家族へ参加し、owner承認前は0件、承認後は同じ人物・記録が見えること、viewerが変更できないことを確認します。

1. ownerが10分以内に自分、家族2人、故人1人を登録する。
2. 故人へ年月精度の命日、架空の戒名、墓所を登録する。
3. 法事へ会場、お布施、参加者、故人との関係を登録する。
4. ホームから人物を検索し、関係と最後に会った場面を確認する。
5. ホームから直近記録を選び、会場、費用、参加者を確認する。
6. 前回記録から下書きを作り、日付・金額・出欠・添付が空であることを確認する。
7. ownerとeditorの同時編集で後の保存に競合画面が出る。
8. 通信を切って保存し、成功・未同期と表示されず入力が画面内に残る。
9. 5MiB超過または不正形式の添付を拒否し、本文との部分成功を区別する。

## 端末・表示

| 対象 | 必須確認 |
|---|---|
| Android実機 | OTP、Photo Picker、通知、外部地図、戻る、APK/AAB更新 |
| iPhone実機 | OTP、写真選択、通知、スワイプ戻る、実機署名 |
| Web共有PC | 未認証遮断、直リンク遮断、30分無操作ロック、一時出力清掃 |
| 320px / 200% | 4タブ、フォーム、ダイアログ、家系図一覧、保存エラー |

## 削除・復旧

- 人物・場所・記録のごみ箱と30日以内の復元。
- owner移譲後の旧owner退会。
- アカウント削除と家族全削除を別々に実データで確認。
- DB、Storage、派生ファイルが30日以内に消去される運用証跡。
- 暗号化バックアップから隔離環境へ復元し、RLS再適用後に件数と添付を照合。

結果は `docs/verification/YYYY-MM-DD_<environment>.md` に記録します。秘密情報や実在人物は記載しません。
